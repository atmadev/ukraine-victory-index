# Каталог джерел і чек-лист збору даних

Для кожного пункту: шукай найсвіжіші дані (пріоритет — останні 30 днів), фіксуй
значення + джерело + дату. Джерела нижче — перевірені стартові точки; якщо джерело
померло чи не оновлюється — шукай альтернативу через веб-пошук і задокументуй заміну
у звіті. Не покладайся на одне джерело для критичної метрики.

Застереження до всіх джерел: офіційні цифри обох сторін (Генштаб ЗСУ, міноборони рф)
— інструменти інфовійни; використовуй їх лише як верхню/нижню межу поряд з
незалежними оцінками.
