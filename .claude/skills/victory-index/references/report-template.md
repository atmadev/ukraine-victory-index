# Шаблон тижневого звіту

Файл: `journal/YYYY-MM-DD.md`. Заповнюй усі розділи; де даних немає — пиши чому.
Дельти (Δ) — відносно попереднього звіту; у першому звіті замість дельт пиши «перший запуск».

| Індекс | Значення | Δ за тиждень |
