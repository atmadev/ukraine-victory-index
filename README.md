# Ukraine Victory Index

Хобі-проєкт: щотижнева оцінка балансу сил у війні росії проти України на основі
відкритих даних. Не військова аналітика — сумлінний аматорський естімейт, цінність
якого в **послідовній динаміці**, а не в абсолютних цифрах.

## Два індекси

| Індекс | Шкала | Семантика |
|--------|-------|-----------|
| **Баланс сил** | −100…+100 | Поточне співвідношення спроможностей. 0 = паритет (відносно асиметричних цілей сторін), плюс = перевага України. |
| **Стратегічний** | 0–100 | Наближення до «стійкого вигідного миру»: гарантії безпеки (40%), ЄС та відбудова (30%), справедливість (30%). 0 = поразка, 100 = мир досягнуто. |

Індекси мають різну семантику і ніколи не усереднюються між собою.

## Структура

- `.claude/skills/victory-index/` — скіл, що збирає дані, рахує індекси і пише звіти
  - `SKILL.md` — процедура запуску
  - `references/methodology.md` — рубрики оцінювання, ваги, формули
  - `references/sources.md` — каталог джерел даних
  - `references/report-template.md` — шаблон звіту
- `journal/` — тижневі звіти (`YYYY-MM-DD.md`)
- `data/history.json` — машиночитна історія індексів (для графіків)

## Використання

У Claude Code в цьому репозиторії: `/victory-index` або просто «порахуй індекс».
Скіл сам збере свіжі дані, оцінить фактори відносно попереднього запуску, запише
звіт у журнал і оновить історію.
